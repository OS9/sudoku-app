# Sudoku — オフライン数独 PWA

iPhone Safari でホーム画面に追加して使える、オフライン対応の数独アプリです。

## 機能
- 9×9数独、初級・中級・上級
- 一意解になる問題を端末内で生成
- 候補数字メモ、1手戻す、消去、ヒント
- ミス回数、タイマー、入力済みマス数
- 途中経過を localStorage に自動保存
- 難易度ごとのベストタイム、クリア記録
- ダーク／ライト切替
- Service Worker によるオフラインキャッシュ

## 起動方法（最初の準備）
PWA と Service Worker は `file://` からでは動作しません。HTTPS または localhost で配信してください。

### 方法 A: PC でローカル確認
Python 3 があるフォルダで実行します。

```bash
python3 -m http.server 8000
```

同じ Wi-Fi の iPhone からアクセスする場合は、PC の LAN IP を使います（例 `http://192.168.1.20:8000`）。ただし iOS では Service Worker の安全なコンテキスト要件により、LAN の HTTP ではオフライン登録できない場合があります。ホーム画面追加・オフライン利用の確認には HTTPS の公開先を推奨します。

### 方法 B: HTTPS で公開（推奨）
1. このフォルダのファイルを静的ホスティングへアップロードします（例: GitHub Pages、Netlify、Cloudflare Pages）。
2. 発行された **HTTPS URL** を iPhone の Safari で開きます。
3. 一度オンライン状態でページを最後まで読み込みます。
4. Safari の共有ボタン →「ホーム画面に追加」→「追加」。
5. ホーム画面の「数独」アイコンから起動します。
6. オフラインで起動できることを確認します。

## 注意
- 初回キャッシュには一度インターネット接続が必要です。
- アプリ本体は外部ライブラリ・外部フォント不要で動作し、ゲームプレイ中に通信を必要としません。
- 進行状況と記録はブラウザの localStorage に保存されます。Safari のWebサイトデータを消去すると失われます。
- ホーム画面への追加には Mac や App Store は不要です。
- これは PWA であり、App Store 配布用のネイティブアプリではありません。

## ファイル
- `index.html`: 画面構造
- `style.css`: モダンなUI、ダーク／ライトテーマ、レスポンシブレイアウト
- `app.js`: 問題生成、入力、ヒント、記録、保存処理
- `sw.js`: オフラインキャッシュ
- `manifest.webmanifest`: ホーム画面起動設定
- `icon.svg`, `icon-180.png`: アプリアイコン（iOS用PNGを含む）
